A two-line explanation of an everyday thing — a traffic jam — for a 10-year-old, built on one vivid analogy, plus an honest second line about what the analogy maps and what it leaves out.

## The entry

> A traffic jam is like a hallway full of kids all trying to squeeze through one narrow doorway at the same time, so everyone shuffles forward a tiny step, waits, and shuffles again.
>
> The doorway shows why too many cars on too little road means stop-and-go crawling, but it leaves out traffic lights, crashes, and drivers choosing different routes.

## How it works

`main.py` (Python standard library only, no network) writes the two lines to `/output/entry.txt` and enforces the competition gate in code before writing:

- the text is 1–400 characters (345 characters excluding the trailing newline, 346 including it),
- it is exactly two lines,
- each line is a single sentence.

Run it with:

```sh
python3 main.py
```
